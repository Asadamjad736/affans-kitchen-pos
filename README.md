# 🍲 Affan's Kitchen - Professional POS System

A complete restaurant Point of Sale (POS) system with daily sales tracking, inventory management, and analytics.

## ✨ Features

- **📋 Menu Management** - Breakfast, Lunch, Dinner categories
- **🧾 Order Processing** - Add items, apply tax & discounts
- **📊 Analytics Dashboard** - Daily sales, category performance
- **📈 Inventory Tracking** - Stock management with alerts
- **💾 Data Persistence** - All data saved to JSON files
- **🖨️ Receipt Generation** - Professional receipts with print option
- **📤 Export Data** - CSV export for analysis
