# 🍲 Affan's Kitchen - POS System

A complete restaurant Point of Sale (POS) system with order taking, daily sales tracking, and inventory management — built as a single-file Streamlit app.

## ✨ Features

- 📋 **Menu Management** — Breakfast, Lunch, and Dinner categories, fully editable
- 🧾 **Order Processing** — Tap to add items, adjustable tax/service %, live running total
- 📊 **Sales Report** — Daily and all-time totals, product-wise revenue breakdown, sales chart
- 📦 **Inventory Management** — Add, edit, enable/disable, or delete menu items and prices
- 💾 **Data Persistence** — All orders and menu data saved to a local SQLite database (`orders.db`)
- 🖨️ **Receipt Generation** — Printable receipt view plus downloadable `.txt` receipts
- 📤 **Export Data** — Download the sales report as CSV
- 🔐 **Passcode Protected** — Simple passcode lock on app entry
- 📱 **Mobile Friendly** — Touch-sized buttons, responsive layout for phones/tablets
